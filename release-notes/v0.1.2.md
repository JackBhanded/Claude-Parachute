# Claude Parachute v0.1.2 — the off switch actually works now

> Paste this straight into the GitHub release body for the `v0.1.2` tag.

🪂 A small but important follow-up to v0.1.1. The window-storm fix landed, but
*turning Parachute off* didn't always stick — this release closes that gap.

### Fixed

- **Turning it off now actually sticks.** The hook detector only recognised the python form of its own hook (`… -m claude_parachute snapshot-hook`). When the packaged build registered itself by its `.exe` name (`"…\Claude Parachute.exe" snapshot-hook`), the app couldn't *find* that hook — so `uninstall-hooks` and the in-app toggle silently did nothing, and re-installs quietly stacked duplicates. The matcher now recognises **both** forms: uninstall removes it cleanly, and install never duplicates.

### Added

- **`Stop the storm` rescue script.** If an older build is still re-opening on you faster than you can update, double-click **`Stop the storm.bat`** (or run `python stop-the-storm.py`). It removes **only** Parachute's hooks from your Claude settings, makes a timestamped backup first, and leaves every other setting untouched. Safe to run twice.

### Get it

Download **`Claude Parachute.exe`** below and double-click. (Windows SmartScreen warns on the unsigned exe → **More info → Run anyway**.) Needs **git** on your PATH.

If you had a runaway window before: run `Stop the storm.bat` once, replace your old exe with this one, then re-arm from inside the app if you want auto-snapshots back.
