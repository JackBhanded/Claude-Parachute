# Claude Parachute v0.1.3 — self-healing hooks

> Paste this into the GitHub release body for the `v0.1.3` tag.

🪂 A small reliability release that makes Parachute's hooks tidy themselves up.

### Fixed

- **No more nagging about a moved exe.** If you ran Parachute from Downloads (or anywhere) and later moved or deleted it, the stale hook would fail after every tool with a `No such file or directory` error. Parachute now **prunes any of its own hooks whose exe has gone missing** — automatically on app launch, at session start, during `parachute doctor`, and before re-arming. It only ever touches *its own* hooks, and it's **OS-aware**: if you run both Cowork (Linux) and the CLI (Windows) off one settings file, neither side removes a hook that's valid for the other.
- **Bash-safe hook path.** Claude Code often runs hooks through Git Bash on Windows, where a `C:\...\` path loses its backslashes. The hook is now registered with forward slashes, so it runs cleanly in cmd, PowerShell, *and* bash.

### Get it

Download **`Claude Parachute.exe`** below and double-click. Keep it somewhere
permanent (not Downloads), then arm it once from the app or `parachute install-hooks`.
(Windows SmartScreen warns on the unsigned exe → **More info → Run anyway**.) Needs **git** on your PATH.
