# Claude Parachute v0.1.1 — stop the window storm

> Paste this straight into the GitHub release body for the `v0.1.1` tag.

🪂 A quick, important fix on top of v0.1.0.

### Fixed

- **Parachute no longer re-opens itself again and again.** With Auto-snapshot turned on, the Claude Code hook was registered pointing at the packaged app — so every tool Claude ran re-launched the **app window** instead of quietly taking a snapshot, piling copies into your taskbar. Now the launcher sends any subcommand (like the hook's `snapshot-hook`) to the command line and never opens a window, and a packaged build registers its hook with a bare subcommand. Already-installed (mis-registered) hooks are handled automatically too.

  If you were affected: update to this version and run **`parachute install-hooks`** once (or toggle Auto-snapshot off and on in the app) to rewrite the hook cleanly. Or `parachute uninstall-hooks` to switch it off entirely.

- **Turning it off now actually sticks.** The hook detector only knew the `claude_parachute` (python) form, so a packaged build that registered itself by its `.exe` name couldn't find — and so couldn't remove — its own hook, while re-installs quietly stacked duplicates. The matcher now recognises both forms: uninstall removes it, and install never duplicates.

- **Stuck on an older build? `Stop the storm`.** If Parachute is still re-opening before you can update, double-click **`Stop the storm.bat`** (or run `python stop-the-storm.py`). It removes only Parachute's hooks from your Claude settings, backs the file up first, and leaves everything else exactly as it was.

### Added

- **Single-instance guard** — opening Parachute when a window is already running now bows out quietly instead of stacking a duplicate.
- **A parachute tray icon** — the system-tray icon is now a little parachute, so it's easy to tell apart from the other fleet tools at a glance.

### Get it

Download **`Claude Parachute.exe`** below and double-click. (Windows SmartScreen warns on the unsigned exe → **More info → Run anyway**.) Needs **git** on your PATH.
