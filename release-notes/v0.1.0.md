# Claude Parachute v0.1.0 — the net for when /rewind can't save you

> Paste this straight into the GitHub release body for the `v0.1.0` tag.

🪂 **First drop.** Claude Code's `/rewind` only remembers Write/Edit changes — the moment something runs through the **Bash tool** (`rm`, `git reset --hard`, `sed -i`, a migration), it's invisible to rewind and gone for good. Parachute fills that blind spot.

It keeps a private shadow-git history of your project and checkpoints the *whole* tree after every tool — Bash included — so you can pull the cord and come back. It never touches your real `.git`.

**Pulling the cord (`parachute restore <n>`)** is the one that saves you — it restores your project to a chosen snapshot, and it's built so you can never make things worse:

1. it takes a fresh safety snapshot of right-now *first*, so the restore is always undoable;
2. it brings the snapshot's files back into your project; and
3. it never deletes files you created since — it only brings the old ones back.

`parachute undo` is the express version: one step back to the snapshot before your last change.

### In this release

- **Shadow-git snapshot engine** — a private history separate from your real `.git`; checkpoints the whole tree, Bash changes included.
- **Auto-snapshots** — `install-hooks` adds a PostToolUse hook (checkpoint after every tool) and a SessionStart baseline, for hands-free cover. `uninstall-hooks` removes only Parachute's hooks.
- **Pull the cord** — `restore <n>` (and quick `undo`): non-destructive, always-undoable recovery, explained above.
- **Manual checkpoints** — `snapshot -m "before the risky bit"` whenever you want a marker.
- **See where you stand** — `list` (snapshots + their restore numbers), `status`, and a light/dark **HTML dashboard**.
- **`doctor`** — a quick health check (Python, git, armed?, hooks?).
- **A calm double-click app** — snapshot timeline, a big **Pull the cord** button (or double-click a snapshot), Snapshot-now, an Auto-snap toggle, and a system-tray companion that keeps the net armed in the background.

### Get it

Download **`Claude Parachute.exe`** below and double-click. (Windows SmartScreen warns on the unsigned exe → **More info → Run anyway**.) Needs **git** on your PATH — Parachute uses it as the snapshot engine.
